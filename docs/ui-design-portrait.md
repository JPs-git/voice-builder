# 在线声音训练 · 竖版 UI 设计规范

设计基准：390 × 844 CSS px。本文记录当前实现的唯一有效规范，更新于 2026-10-14。
适用范围：宽度不超过 768px 的竖屏工作区，包含「声音分析」(`/`) 与「音高参考」(`/practice`) 两个 Tab；宽度超过 768px 时沿用横版布局。

## 页面布局

页面由共享 Header、页面 Tab、当前页面内容和固定底部操作栏组成。Header 的 Tab 按「声音分析」「音高参考」顺序切换；两个页面复用录音、清除和回放 Dock。声音分析页显示实时反馈、F0 与共振峰图表，并在 Dock 提供训练目标入口；音高参考页仅显示可翻页音域的钢琴键盘和复用横版图表的音高图。

### 页面切换

- 顶栏 Tab 顺序为「声音分析」「音高参考」，当前路由对应选中项。
- `/practice` 与 `/` 保持可直接访问；浏览器前进/后退同步更新选中项。
- 「更多」菜单仅承载导入、音频操作、配置、帮助和关于，不再放页面切换入口。
- 页面切换时录音、回放和分析数据保持连续；两个页面只挂载当前内容。

### 音高参考页

- 内容顺序为钢琴键盘、音高图。
- 音高参考页不显示实时反馈卡或 Dock 训练目标入口；切换到声音分析页可从 Dock 打开训练目标模态框。
- 钢琴默认显示 C2–C4；左右滑动键盘时音域跟随手指连续平移，窗口保持约两个八度并限制在 C2–C6 之间。轻点琴键播放对应参考音，检测到的音高在 C2–C6 内时高亮。
- 音高图复用横版的音符纵轴（G2–E5）、自然音参考线和 C4 标记；竖版仅收紧图表网格边距与轴标签字号，沿用横版曲线、时间轴、回放游标和悬浮提示行为。
- 页面内容可以纵向滚动；固定 Dock 和设备安全区不遮挡钢琴或图表。

| 项目 | 当前规范 |
|---|---|
| 应用高度 | `100dvh`，以 `100vh` 回退 |
| 页面背景 | `#F4FAFF` |
| 主内容内边距 | 左右 16px；声音分析底部 90px、音高参考底部 96px，均加 `env(safe-area-inset-bottom)` |
| 基准内容宽度 | 358px（390 − 16 × 2） |
| 页面区块间距 | 12px |
| 页面卡片间距 | 12px |
| 声音分析页 | 实时反馈、基频与共振峰图表按原布局堆叠 |
| 音高参考页 | 钢琴键盘、音高图纵向排列 |
| 滚动 | 两页内容分别纵向滚动；矮视口允许滚动，固定 Dock 不遮挡内容 |

设备状态栏、时间、电量及系统底部手势条由设备提供，应用不绘制模拟系统栏。底部留白消费浏览器提供的安全区值。

## 顶部 Header

- 高度固定 **64px**，内边距 `8px 16px`，内容垂直居中。
- 背景 `#F4FAFF`，无底部分隔线；保持顶部可见，层级 20。
- 左侧为 32 × 32px 品牌 Logo 和“在线声音训练”；宽度 ≤390px 时 Logo 28px、标题 15px。
- 标题字号 18px（窄屏 15px）、字重 700、行高 26px，颜色 `#0A2344`。
- 品牌图文间距 6px；竖屏隐藏副标题和横版操作按钮组。
- 中间为 40px 高的分段 Tab，依次为「声音分析」「音高参考」，字号 12px，激活项白底蓝字。
- 右侧更多按钮为 30 × 28px，圆角 9px，白色背景和细边框。
- 更多菜单承载导入、音频操作、配置、帮助、关于；禁用状态跟随实际操作可用性。

## 实时反馈栏

反馈栏始终单行排列：信号图标 → 实时反馈 → F0 数值及状态图标 → F1 数值及状态图标 → F2 数值及状态图标。竖屏不显示声区徽章。

| 项目 | 当前规范 |
|---|---|
| 最小高度 | 50px |
| 内边距、元素间距 | 左右 10px；间距 6px |
| 表面 | `rgba(255,255,255,.88)`，无边框 |
| 圆角、阴影 | 9px；`0 2px 10px #23558B06` |
| 标题 | 11px，700，`#0A2344` |
| 数值列 | 等分剩余宽度，左侧 1px `#E0E8F3` 分隔线，左内边距 5px |
| 频率标签与数值 | 9px、字重 700；数值按状态着色，取整显示；按未取整值比较目标 |
| 单位 | 有效数值显示 Hz，8px、字重 500，与数值同色；缺失值隐藏单位 |

F0/F1/F2 标签分别使用绿 `#12B886`、红 `#F04B6A`、蓝 `#3F83F8`。标签底色为对应颜色的 5% 淡色。

每项数值单独与该项当前目标闭区间比较：范围内显示绿色 `var(--hit)` 与 `✓`；高于上限或低于下限均显示橙色 `var(--warn)`，分别使用 `↑` 和 `↓`。null、undefined、非有限值、零或负数只显示中性灰 `var(--text-mute)` 的 `--`，隐藏 Hz 且不显示状态图标。箭头或对勾位于 Hz 后，例如 `300 Hz ↑`、`240 Hz ✓`，始终预留固定宽度；数字、Hz、状态图标同步变色，标签身份色保持原样。箭头表示当前值相对目标的位置，不代表建议调整方向。

每列通过可访问名称说明指标、数值及高低状态，状态图标标记为 aria-hidden；不使用逐帧 aria-live 播报。隐藏的系列不显示对应列；目标变化立即更新方向，清空后数值恢复占位符。

## 图表卡片通用规范

- 表面 `rgba(255,255,255,.88)`，无边框，圆角 9px，阴影 `0 2px 10px #23558B06`。
- 内边距：上 10px、左右 10px、下 12px；标题区与绘图区间距 6px。
- 标题区高 28px，左右排列标题和图例。
- 标题字号 14px、字重 700、颜色 `#0A2344`；前置 20 × 20px SVG 图标，颜色 `#354C6A`。
- ECharts 网格留白：左 42px、右 0、上 10px、下 6px，相对于绘图容器计算。
- 网格线 `#EDF2F7`；坐标轴 `#B8C4D1`；纵轴标签 9px、`#7D8DA8`，带 Hz 单位。
- 横轴时间标签隐藏，保留网格；纵轴固定在绘图区左边，不随时间零点移动。
- **录音期间两个图谱均只显示最近 10 秒**，横轴范围随最新帧滚动：`[最新时间 − 10, 最新时间]`。例如第 35 秒显示 25–35 秒，第 36 秒显示 26–36 秒。录音不足 10 秒时窗口前方可以留空。
- 无数据时显示空态提示；录音或导入后显示实际分析数据，不内置示例曲线。
- 回放时显示红色播放游标，并保留悬浮查看数据的交互。

### 基频 F0

- 标题为“基频 F0”，其中 F0 使用 13px、600、`#00B990`。
- 纵轴范围 0–500Hz，刻度间隔 100Hz。
- 当前值使用 `#3F83F8`、2px 折线；最新有效采样点为 7px 圆点，带蓝色柔光。
- 男声参考区间 160–240Hz，参考虚线 200Hz；淡蓝区域 `rgba(63,131,248,.08)`、虚线 `#8BB9FF`、标签 `#3F83F8`。
- 女声参考区间 270–350Hz，参考虚线 300Hz；淡粉区域 `rgba(233,71,99,.08)`、虚线 `#F4A0B1`、标签 `#E94763`。
- 图例依次为“当前值”“目标区间”“目标线”，字号 8px，颜色 `#788FAF`，组间距 12px。
- 图例符号分别为 13 × 3px 蓝色实线、14 × 14px 淡粉色方块、13px 宽虚线。

### 共振峰

- 纵轴范围 0–3500Hz，间隔 500Hz；文字仅显示 0、1000、2000、3000、3500Hz。
- F0/F1/F2 数据分别使用 `#12B886`、`#F04B6A`、`#3F83F8`，显示 2px 圆点，连接线宽度为 0。
- 三组目标区域分别使用淡绿、淡蓝、淡橙；目标虚线分别为 `#12B886`、`#3F83F8`、`#F4B84A`。
- 目标区间来自当前元音预设及用户调整，虚线位于对应区间中点；不可将设计示例中的频率数值硬编码为目标。
- 标签为“F0 目标”“F1 目标”“F2 目标”；F1 标签位于线内侧下方，F0/F2 位于线内侧上方。
- 右侧图例为三个可切换胶囊按钮：最小宽度 34px、高 21px、9px 字号、左右内边距 7px、间距 4px，圆点直径 6px。
- 点击图例切换对应系列及目标标记的可见性；关闭时图例透明度 0.35。

## 底部操作栏

固定在视口底部，层级 30。录音按钮水平居中，清除图谱与回放分列两侧；声音分析页显示当前目标入口，音高参考页隐藏该入口。

| 项目 | 当前规范 |
|---|---|
| 最小高度 | `80px + env(safe-area-inset-bottom)` |
| 内边距 | 上 8px、左右 20px、下 `16px + env(safe-area-inset-bottom)` |
| 元素间距 | 8px |
| 顶部圆角 | 左右 34px，底部不设圆角 |
| 背景 | `rgba(255,255,255,.96)`，无背景渐变 |
| 阴影 | `0 -4px 20px rgba(44,75,105,.06)` |

### 当前目标入口（仅声音分析页）

- 高 26px，圆角 18px，背景 `#F4F7FC`。
- 内容为当前元音、文字“当前目标”和右箭头。
- 元音底为淡粉圆形，最小宽度 27px、高 26px、字号 17px；提示文字 10px、`#6C83A4`。
- 点击打开居中的“训练目标”模态框，提供元音按钮、双滑杆和上下限数字输入。滑杆实时生效，数字输入在失焦后校验、生效并保存；关闭按钮、遮罩或 Esc 均先使输入框失焦再关闭弹窗，不显示底部按钮栏。

### 训练目标模态框

- 元音 a/o/e/i/u/ü 使用六个按钮切换，每个元音保留自己的自定义目标。
- F0、F1、F2 使用绿、粉、蓝三个分组；每组提供上下限输入和双滑杆，数值同步。
- 滑杆与横屏输入框复用 `BAND_INPUT_LIMITS`：F0 为 0–500 Hz、步长 5 Hz；F1/F2 为 0–3500 Hz、步长 10 Hz；范围分别来自图谱与目标调节共享的 F0_CHART_RANGE、FORMANT_CHART_RANGE，算法检测范围独立保留。
- 横竖屏数字输入共用规则：输入过程只更新草稿，不改变目标、图表或持久化设置；失焦时校验并提交，Enter 触发失焦，不重复提交。保留输入精度，越界值限制到配置边界内，始终要求下限小于上限；空值或无效区间恢复最近有效值。
- F1/F2 自身上下限最小间隔统一为 50 Hz（`FORMANT_MIN_GAP_HZ`）。数字下限过高时自动收敛到当前上限减 50，上限过低时自动收敛到当前下限加 50，失焦显示并保存调整后的值。
- 卡片标题不显示规则文字或“ⓘ 规则”按钮。手动输入失焦触发越界、间隔不足、空值等校验时，用输入框上方的白底橙边浮层气泡解释原因与调整结果，输入框显示橙色描边。滑杆触及轨道频率端点（F0 0/500 Hz、F1/F2 0/3500 Hz）或自身最小间距时静默停止；仅在轨道中间受 F1 上限与 F2 下限相互限制时提示。拖离受限边界立即清除气泡，同次拖动中相同提示只触发一次。气泡在独立浮层中固定向上弹出，逐一避让所有可见滑杆，并跟随滚动和软键盘调整位置；空间不足时文字区可滚动，不占布局空间，保持卡片高度不变；可手动关闭。重新编辑、切换元音或恢复默认时清除提示。
- F1 上限提交时若大于 F2 下限，自动收敛到 F2 下限，允许相等；F1 上限滑块也受此边界限制。若此边界与 50 Hz 自身间隔冲突、没有可用合法值，则提示先调整另一端或 F2 下限。
- 始终保持 `F1 下限 < F1 上限 ≤ F2 下限 < F2 上限`，两个自身区间同时至少相隔 50 Hz。F2 下限低于 F1 上限时，输入失焦后自动设为 F1 上限并说明原因；滑杆在相同边界停止并提示。双端输入和滑杆复用同一份边界规则。数据层在更新、保存、切换预设、读取旧自定义值时统一规范化；旧数据冲突时优先保留 F1 范围，提高 F2 下限，必要时提高 F2 上限，同时为两个区间预留 50 Hz 并遵守频率范围。
- 两个滑块保持同一水平线，按钮直径 14px，不交叉、不推动另一端。拖动时按轨道宽度计算 16px 的中心间隔，已有更窄的合法区间以拖动起始间隔为准，不因首次拖动而跳变；同次手势的间隔保持不变。键盘独立按频率步长调整，F1/F2 始终至少保留 50 Hz。手动输入可比视觉间隔更小，但 F1/F2 仍至少相隔 50 Hz。点击轨道按触点距离选择最近的手柄。
- 支持方向键单步、PageUp/PageDown 十步、Home/End 到可用边界。
- 说明文字右侧的重置图标与横屏共用同一个操作和确认文案：确认后恢复全部元音的默认目标、清除所有自定义覆盖值，并切换到元音 a；取消时保留所有设置和当前选择。重置同步清除输入草稿与校验气泡。
- 打开弹窗不暂停录音，调整应用于后续反馈；遮罩禁止操作背景，弹窗关闭后焦点返回入口。
- 内容区可滚动，顶部关闭按钮固定；跟随可视视口调整高度，避免软键盘遮挡操作。弹窗限制 Tab 焦点并锁定背景滚动。

### 录音按钮

- 相对视口水平居中：`left: 50%` 配合水平平移，不受左右按钮宽度影响。
- 外圈 62 × 62px，圆形，背景 `#FFEBF2`，顶部外边距 −8px。
- 主按钮 50 × 50px，背景 `linear-gradient(130deg,#FF3364,#EE3D70)`，白色麦克风 SVG 为 25 × 25px。
- 空闲时可开始录音；请求麦克风权限时禁用；录音时可停止，显示脉冲效果与计时。
- 计时位于操作栏底部中央，字号 10px；不显示额外的“点击开始录音”提示文字。
- 遵循 `prefers-reduced-motion`，减少动态效果时关闭脉冲。

### 清除与回放

- 胶囊按钮高 27px、圆角 18px、左右内边距 8px，文字 10px、`#6D83A4`。
- 背景 `#FFFFFFA8`，边框 1px `#E4EBF5`，图标 14 × 14px、`#294566`。
- 无数据时禁用，透明度 0.45；麦克风授权中同时禁用回放。
- 回放期间按钮文字变为“停止”。
- 音频操作统一经过工具栏命令入口：先停止已有回放；执行非录音操作前停止录音。
- 清除仅清除分析数据，保留配置及目标范围。配置、帮助、关于不打断音频。

## 响应式与状态要求

| 条件 | 调整 |
|---|---|
| 宽度 ≤768px | 使用竖版布局及 64px Header |
| 宽度 ≤384px | 底部栏左右内边距 10px、间距 4px；清除/回放按钮左右内边距 5px |
| 宽度 ≤360px | 主内容左右内边距 10px；基频图例间距 5px；反馈栏左右内边距 6px、间距 4px，隐藏信号图标，标题 10px |

按钮需要具备可访问名称、可见键盘焦点及正确的禁用状态。保留录音、授权、无数据、已有数据、回放中的状态反馈。

### 合并前风险修复

- 横屏与竖屏使用相同的输入校验解释气泡，避免静默调整数值；点击其他控件时关闭提示。
- 旧目标被范围或顺序规则规范化前，将完整原始存储备份到 `voicebuilder-presets-before-target-rules-v1`，已有备份不会被后续迁移覆盖。备份保留在当前浏览器本地，存储权限或配额不足时无法保证备份写入。
- 新增回归覆盖：窄区间键盘/触摸调整方向、边界提示、气泡位置避让、关闭前失焦提交、焦点返回、横竖屏全部元音重置及取消、旧数据迁移备份和目标顺序规范化。

## 主动帮助体验（2026-10-15）

- 移除随机轮播小提示，不自动打开帮助弹窗；首次使用提示采用独立的浏览器本地关闭/完成标记。
- 「更多 → 帮助」打开快速上手；两个页面的空状态不再提供上手/音高说明按钮。
- 底部悬浮条文案为「第一次使用？」／「了解录音、读图与目标设置」，「查看说明」打开快速上手帮助文档，右侧可以关闭。
- 悬浮条脱离文档流，位于 Dock 实测顶部上方 10px，不压缩图表；文字可换行，按钮和关闭命中区域至少 44px。操作栏高度变化时跟随定位。
- 无数据空闲时展示；授权、录音、回放、已有数据及应用弹层打开时暂时隐藏。关闭或首次有效分析后持久隐藏，清除图谱不会恢复；仅阅读帮助不计为完成。
- 基频、共振峰标题旁问号打开「读图与反馈」；音高图问号打开对应说明。
- 六个帮助主题共享横竖屏内容，仅操作位置文案随布局更新；预设表和范围来自配置，表中只展示 F0/F1/F2 默认值。
- 帮助采用模态框，长内容在正文滚动，Esc 关闭、Tab 焦点约束、关闭返回入口焦点；不打断录音或回放。
- 竖屏空状态保持事件穿透。悬浮提示只让卡片接收事件，不拦截其他图表区域；关闭后图表位置和高度不变。
- 应用帮助、配置、关于和训练目标设置同时仅打开一个弹层；保留现有输入校验气泡，不重新加入规则按钮。
- 横屏复用同一首次提示和本地标记，关闭或完成在两端持续生效；横屏悬浮条定位在右下角，竖屏保持 Dock 上方定位。
- 帮助期间切换横竖屏保留主题与阅读焦点；关闭时原入口不可用则回退到当前录音按钮，录音禁用时回退当前帮助/更多。
- 竖屏目标模态框切换横屏时关闭并清除其打开状态，不留下不可见弹层状态影响首次提示。


## 统计录音页常驻说明（2026-10-25）

统计录音页使用批准的 A 版两行浅蓝提示，位于页签与阅读卡之间、约 52px 高。第一行「建议录制 30–60 秒，最长 60 秒」（30–60 秒加粗），第二行「典型音高、常用范围、分布与回放」，右侧问号打开统一帮助的统计分析主题。无关闭按钮，所有录音任务阶段保持可见，不受全局首次标记影响，也不叠加原悬浮提示。报告详情不显示，其他页面沿用既有帮助体验。阅读卡填满其余高度、正文在 article 内滚动，继续预留 Dock 实测高度。
