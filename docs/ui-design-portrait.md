# 在线声音训练 · 竖版 UI 设计规范

设计基准：390 × 844 CSS px。本文记录当前实现的唯一有效规范，更新于 2026-09-29。
适用范围：宽度不超过 768px 的竖屏工作区，包含「声音分析」(`/`) 与「音高参考」(`/practice`) 两个 Tab；宽度超过 768px 时沿用横版布局。

## 页面布局

页面由共享 Header、页面 Tab、当前页面内容和固定底部操作栏组成。Header 的 Tab 按「声音分析」「音高参考」顺序切换；两个页面复用录音、清除和回放 Dock。声音分析页显示实时反馈、F0 与共振峰图表，并在 Dock 提供训练目标入口；音高参考页仅显示可翻页音域的钢琴键盘和复用横版图表的音高图。

### 页面切换

- 顶栏 Tab 顺序为「声音分析」「音高参考」，当前路由对应选中项。
- `/practice` 与 `/` 保持可直接访问；浏览器前进/后退同步更新选中项。
- 「更多」菜单仅承载导入、音频操作、配置、帮助和关于，不再放页面切换入口。
- 页面切换时录音、回放和分析数据保持连续；两个页面只挂载当前内容。

### 音高参考页

- 内容顺序为钢琴键盘、音高图。
- 音高参考页不显示实时反馈卡或 Dock 训练目标入口；切换到声音分析页可从 Dock 打开训练目标抽屉。
- 钢琴默认显示 C2–C4；左右箭头每次平移一个八度，范围下限为 C2–C4、上限为 C4–C6。琴键仍可播放对应参考音，检测到的音高在当前范围内时高亮。
- 音高图复用横版的音符纵轴（G2–E5）、自然音参考线和 C4 标记；竖版仅收紧图表网格边距与轴标签字号，沿用横版曲线、时间轴、回放游标和悬浮提示行为。
- 页面内容可以纵向滚动；固定 Dock 和设备安全区不遮挡钢琴或图表。

| 项目 | 当前规范 |
|---|---|
| 应用高度 | `100dvh`，以 `100vh` 回退 |
| 页面背景 | `#F4FAFF` |
| 主内容内边距 | 左右 16px；声音分析底部 90px、音高参考底部 96px，均加 `env(safe-area-inset-bottom)` |
| 基准内容宽度 | 358px（390 − 16 × 2） |
| 页面区块间距 | 12px |
| 页面卡片间距 | 12px |
| 声音分析页 | 实时反馈、基频与共振峰图表按原布局堆叠 |
| 音高参考页 | 钢琴键盘、音高图纵向排列 |
| 滚动 | 两页内容分别纵向滚动；矮视口允许滚动，固定 Dock 不遮挡内容 |

设备状态栏、时间、电量及系统底部手势条由设备提供，应用不绘制模拟系统栏。底部留白消费浏览器提供的安全区值。

## 顶部 Header

- 高度固定 **64px**，内边距 `8px 16px`，内容垂直居中。
- 背景 `#F4FAFF`，无底部分隔线；保持顶部可见，层级 20。
- 左侧为 32 × 32px 品牌 Logo 和“在线声音训练”；宽度 ≤390px 时 Logo 28px、标题 15px。
- 标题字号 18px（窄屏 15px）、字重 700、行高 26px，颜色 `#0A2344`。
- 品牌图文间距 6px；竖屏隐藏副标题和横版操作按钮组。
- 中间为 40px 高的分段 Tab，依次为「声音分析」「音高参考」，字号 12px，激活项白底蓝字。
- 右侧更多按钮为 30 × 28px，圆角 9px，白色背景和细边框。
- 更多菜单承载导入、音频操作、配置、帮助、关于；禁用状态跟随实际操作可用性。

## 实时反馈栏

反馈栏始终单行排列：信号图标 → 实时反馈 → 状态徽标 → F0 数值 → F1 数值 → F2 数值。

| 项目 | 当前规范 |
|---|---|
| 最小高度 | 50px |
| 内边距、元素间距 | 左右 10px；间距 6px |
| 表面 | `rgba(255,255,255,.88)`，无边框 |
| 圆角、阴影 | 9px；`0 2px 10px #23558B06` |
| 标题 | 11px，700，`#0A2344` |
| 状态徽标 | 高 23px，9px 字号，胶囊圆角，左右内边距 6px |
| 数值列 | 等分剩余宽度，左侧 1px `#E0E8F3` 分隔线，左内边距 5px |
| 频率标签与数值 | 9px；数值颜色 `#0A2344`，取整显示 |
| 单位 | 每列显示 Hz，8px，`#7288A6` |

F0/F1/F2 标签分别使用绿 `#12B886`、红 `#F04B6A`、蓝 `#3F83F8`。标签底色为对应颜色的 5% 淡色。

无有效声音时显示“等待声音”，数值为 `--`。可见频率全部命中目标时显示“目标范围内”，徽标底色 `#E8FBF6`、文字 `#00B58D`。偏离目标时显示“偏高”或“偏低”，使用警示色。隐藏的共振峰系列不参与反馈栏显示与状态汇总。

## 图表卡片通用规范

- 表面 `rgba(255,255,255,.88)`，无边框，圆角 9px，阴影 `0 2px 10px #23558B06`。
- 内边距：上 10px、左右 10px、下 12px；标题区与绘图区间距 6px。
- 标题区高 28px，左右排列标题和图例。
- 标题字号 14px、字重 700、颜色 `#0A2344`；前置 20 × 20px SVG 图标，颜色 `#354C6A`。
- ECharts 网格留白：左 42px、右 0、上 10px、下 6px，相对于绘图容器计算。
- 网格线 `#EDF2F7`；坐标轴 `#B8C4D1`；纵轴标签 9px、`#7D8DA8`，带 Hz 单位。
- 横轴时间标签隐藏，保留网格；纵轴固定在绘图区左边，不随时间零点移动。
- **录音期间两个图谱均只显示最近 10 秒**，横轴范围随最新帧滚动：`[最新时间 − 10, 最新时间]`。例如第 35 秒显示 25–35 秒，第 36 秒显示 26–36 秒。录音不足 10 秒时窗口前方可以留空。
- 无数据时显示空态提示；录音或导入后显示实际分析数据，不内置示例曲线。
- 回放时显示红色播放游标，并保留悬浮查看数据的交互。

### 基频 F0

- 标题为“基频 F0”，其中 F0 使用 13px、600、`#00B990`。
- 纵轴范围 0–500Hz，刻度间隔 100Hz。
- 当前值使用 `#3F83F8`、2px 折线；最新有效采样点为 7px 圆点，带蓝色柔光。
- 男声参考区间 160–240Hz，参考虚线 200Hz；淡蓝区域 `rgba(63,131,248,.08)`、虚线 `#8BB9FF`、标签 `#3F83F8`。
- 女声参考区间 270–350Hz，参考虚线 300Hz；淡粉区域 `rgba(233,71,99,.08)`、虚线 `#F4A0B1`、标签 `#E94763`。
- 图例依次为“当前值”“目标区间”“目标线”，字号 8px，颜色 `#788FAF`，组间距 12px。
- 图例符号分别为 13 × 3px 蓝色实线、14 × 14px 淡粉色方块、13px 宽虚线。

### 共振峰

- 纵轴范围 0–3500Hz，间隔 500Hz；文字仅显示 0、1000、2000、3000、3500Hz。
- F0/F1/F2 数据分别使用 `#12B886`、`#F04B6A`、`#3F83F8`，显示 2px 圆点，连接线宽度为 0。
- 三组目标区域分别使用淡绿、淡蓝、淡橙；目标虚线分别为 `#12B886`、`#3F83F8`、`#F4B84A`。
- 目标区间来自当前元音预设及用户调整，虚线位于对应区间中点；不可将设计示例中的频率数值硬编码为目标。
- 标签为“F0 目标”“F1 目标”“F2 目标”；F1 标签位于线内侧下方，F0/F2 位于线内侧上方。
- 右侧图例为三个可切换胶囊按钮：最小宽度 34px、高 21px、9px 字号、左右内边距 7px、间距 4px，圆点直径 6px。
- 点击图例切换对应系列及目标标记的可见性；关闭时图例透明度 0.35。

## 底部操作栏

固定在视口底部，层级 30。录音按钮水平居中，清除图谱与回放分列两侧；声音分析页显示当前目标入口，音高参考页隐藏该入口。

| 项目 | 当前规范 |
|---|---|
| 最小高度 | `80px + env(safe-area-inset-bottom)` |
| 内边距 | 上 8px、左右 20px、下 `16px + env(safe-area-inset-bottom)` |
| 元素间距 | 8px |
| 顶部圆角 | 左右 34px，底部不设圆角 |
| 背景 | `rgba(255,255,255,.96)`，无背景渐变 |
| 阴影 | `0 -4px 20px rgba(44,75,105,.06)` |

### 当前目标入口（仅声音分析页）

- 高 26px，圆角 18px，背景 `#F4F7FC`。
- 内容为当前元音、文字“当前目标”和右箭头。
- 元音底为淡粉圆形，最小宽度 27px、高 26px、字号 17px；提示文字 10px、`#6C83A4`。
- 点击打开“训练目标”抽屉，可切换元音并编辑 F0/F1/F2 目标范围；通过关闭按钮或遮罩关闭。

### 录音按钮

- 相对视口水平居中：`left: 50%` 配合水平平移，不受左右按钮宽度影响。
- 外圈 62 × 62px，圆形，背景 `#FFEBF2`，顶部外边距 −8px。
- 主按钮 50 × 50px，背景 `linear-gradient(130deg,#FF3364,#EE3D70)`，白色麦克风 SVG 为 25 × 25px。
- 空闲时可开始录音；请求麦克风权限时禁用；录音时可停止，显示脉冲效果与计时。
- 计时位于操作栏底部中央，字号 10px；不显示额外的“点击开始录音”提示文字。
- 遵循 `prefers-reduced-motion`，减少动态效果时关闭脉冲。

### 清除与回放

- 胶囊按钮高 27px、圆角 18px、左右内边距 8px，文字 10px、`#6D83A4`。
- 背景 `#FFFFFFA8`，边框 1px `#E4EBF5`，图标 14 × 14px、`#294566`。
- 无数据时禁用，透明度 0.45；麦克风授权中同时禁用回放。
- 回放期间按钮文字变为“停止”。
- 音频操作统一经过工具栏命令入口：先停止已有回放；执行非录音操作前停止录音。
- 清除仅清除分析数据，保留配置及目标范围。配置、帮助、关于不打断音频。

## 响应式与状态要求

| 条件 | 调整 |
|---|---|
| 宽度 ≤768px | 使用竖版布局及 64px Header |
| 宽度 ≤384px | 底部栏左右内边距 10px、间距 4px；清除/回放按钮左右内边距 5px |
| 宽度 ≤360px | 主内容左右内边距 10px；基频图例间距 5px；反馈栏左右内边距 6px、间距 4px，隐藏信号图标，标题 10px |
| 可用高度不足 | 主内容可滚动，底部操作栏固定；分析图表组最小高度 420px，音高图卡片填充剩余高度且最小高度 300px |

按钮需要具备可访问名称、可见键盘焦点及正确的禁用状态。保留录音、授权、无数据、已有数据、回放中的状态反馈。
