# 在线声音训练 · UI 与帮助交互规范

更新于 2026-10-20。本文记录当前实现；竖屏视觉细节见 `ui-design-portrait.md`，历史方案见 Git 历史及 `docs/superpowers/`。

## 页面与主要操作

- 「实时分析」显示基频、共振峰、训练目标和实时反馈；「音高参考」显示钢琴键盘与音高图。
- 宽度超过 768px 使用横版：顶栏直接提供录音、导入音频、回放、清空，配置、帮助、关于收进「更多」。统计分析页取消始终可达，不提供清除本次。录音页有成功记录时提供「查看上次结果」，详情页仅保留来源返回及帮助、关于，不提供录音或导入。
- 横版采用 C 版下划线导航，页签区宽 320px，左右等宽区域确保导航中心对齐整个窗口中心。1000px 以下的窄横屏中，页签单独占一行居中；1280px 以下隐藏副标题与次要操作按钮文字，保留按钮名称和提示。
- 宽度不超过 768px 使用竖版：顶部 Tab 切换页面，更多菜单提供导入、配置、帮助等操作，底部提供录音、清除与回放；声音分析页另有当前目标入口。
- 帮助、配置、关于及目标设置同时只打开一个；阅读帮助不停止录音或回放，不申请麦克风权限。

## 主动帮助入口

不显示随机小提示，不自动打开帮助模态框。横竖屏共用一次性的首次使用悬浮提示，记录同一个本地关闭/完成标记。

| 入口 | 打开的主题 |
|---|---|
| 顶栏「更多 → 帮助」 / 竖屏「更多 → 帮助」 | 快速上手 |
| 首次使用悬浮提示「查看说明」 | 统计录音页为统计分析；其他页为快速上手 |
| 基频、共振峰标题旁的问号按钮 | 读图与反馈 |
| 音高图标题旁问号 | 音高参考 |

- 图表说明通过点击打开，支持键盘操作，不依赖悬停。
- 两端空状态均仅保留说明，帮助通过一次性悬浮条、图表问号或菜单主动打开。
- 空状态保持事件穿透；悬浮条仅卡片接收点击，不拦截图表其他区域。
- 目标卡片不增加「ⓘ 规则」入口；原有必要的校验气泡继续使用。

### 共享首次使用悬浮提示

- 标题「第一次使用？」、副文案「了解录音、读图与目标设置」，按钮「查看说明」，右侧可关闭；只打开帮助文档，不提供交互式步骤引导。
- 脱离文档流：横屏右下角距右/底边 24px、宽 400px；竖屏在实际底部操作栏上方 10px，左右 12px、最大宽 400px。不改变图表高度，定位外层保持事件穿透。
- 实时分析、音高参考和统计录音页共用一份状态；未处理提示不因进入统计页而消失。无数据空闲时显示；授权、录音、回放、已有数据或设置弹层打开时暂时隐藏。
- 关闭或首次产生任一有限且 >0 的 F0/F1/F2 分析值后持续隐藏，录音与导入同样适用。仅查看帮助不计为完成。
- 本地键 `voicebuilder-intro-hint-v1` 仅保存布尔标记；清空图谱不清除它。存储受限时当前会话仍有效，刷新可能再次出现。无历史标志的老用户首次上线也可能看到一次。
- 横竖屏空状态均不放置上手/音高说明按钮，标题问号与菜单/顶栏帮助持续可用。

## 帮助面板

使用共享 Modal，标题为「使用说明」，正文顶部有七个主题按钮：快速上手、读图与反馈、训练目标、录音与导入、遇到问题、音高参考、统计分析。

- 快速上手分为开始录音、观察自己的声音、选择目标并回放三步。
- 根据当前横竖屏说明实际操作位置；切换布局保留当前主题。
- 章节切换后正文回到顶部；长内容在正文区域滚动，关闭按钮保持可用。
- 支持 Esc 关闭、Tab 焦点约束，关闭后焦点返回原入口；入口已退出或不可见时返回当前录音按钮，录音禁用则退到横屏帮助/竖屏更多。跨布局不重新聚焦帮助正文或重置主题。
- 帮助文档不增加提示计时器或轮播；首次提示的隐藏规则和独立标记见上节。

## 数据来源与说明准确性

- 主题、文案统一由 `src/content/helpContent.ts` 维护。
- 默认元音表直接读取 `VOWEL_PRESETS`，只显示元音与 F0/F1/F2，明确它是默认值而不是用户自定义目标。
- 图谱可调范围、固定基频参考区间、最小间隔读取 `src/config/analysisRanges.ts`。
- 录音保留窗口、导入时长限制读取 `src/config/audioLimits.ts`，当前均为 10 秒；持续录音不会自动停止。
- 固定基频参考色带与可编辑训练目标分开说明；命中目标不代表对声音质量的完整评价。
- 按钮名使用「导入音频」；WAV、MP3、M4A 是否能解码取决于编码与浏览器支持。
- 数字输入失焦或 Enter 后提交，竖屏滑杆即时更新。恢复默认值清除全部元音自定义并切回 a，需确认。
- 排错分别说明权限、设备、无有效曲线、共振峰波动、文件过长或解码失败，避免统一要求刷新。

## 验收

检查横竖屏的入口、章节切换、焦点返回、360px 窄屏及矮屏正文滚动。保持录音、回放、导入和目标设置流程；页面静置后不出现自动随机提示。

## 统计分析页

第三个独立路由 `/recording`，导航为实时分析、音高参考、统计分析。横屏录音页顶栏提供开始/暂停/继续、暂停后的完成录制、取消、导入、查看上次结果（有记录时）、帮助和关于，不提供清除本次；下方为横向设置条及居中阅读卡，默认 22px 字号，可调整 18–26px。仅提供三篇原创短文，不区分朗读/自由说话模式。录音中不显示图像辅助和之前的报告，不运行 F0 分析。

新页录音按样本在累计 60 秒自动暂停，仍需确认完成，导入超过 60 秒会拒绝，旧页 10 秒窗口不变。暂停后点击「完成录制」才由本地 Worker 分析整段音频，导入仍直接分析，报告仅保留典型 F0（中位数）、P10、P90 及一张全宽直方图。统计范围独立为 60–500Hz，包含 500Hz，超范围帧保留原始值并单独记录排除数量、时长与候选时长占比；实时/音高参考范围不变。直方图按 10Hz 分箱，纵轴为有效时间占比，标出三项分位指标；有效数据不足 3 秒时隐藏数值与分位标记。360px 下典型值单独一行、P10/P90 两列。完整回放保留播放/暂停、时间进度与拖动定位；移除极值、变化幅度、时间曲线、图表定位和「回听此处」，不裁剪原音频。

离开统计录音页会停止采集并保留为暂停草稿，返回可继续或完成，不隐式分析，报告与参考内容设置保留；进入本页会暂停旧实时采集和回放并保留旧图谱。取消和失败不覆盖上一份成功报告；刷新不保留音频。该页默认打开统一帮助中的统计分析主题，说明录制、统计口径和完整回放。

## 统计分析页竖屏操作（2026-10-19）

竖屏沿用胶囊页签，三个页面共用品牌、更多菜单与居中的页签两行顶栏。统计分析页复用 RecordDock：准备时左侧选短文、中央麦克风开始录音，有旧报告时右侧显示「查看上次结果」；首次准备右侧留空。详情不渲染 Dock，将「返回录音」放在报告标题右侧同一行，不保留底栏背景或高度。录音时中央暂停，暂停后中央继续、右侧完成录制；授权、读取和分析时禁用主操作，取消放在顶部更多菜单，左侧保留文章选择。录音页的导入、帮助、关于放在更多菜单，详情更多菜单只有帮助、关于，回放在报告内操作。不显示训练目标，原实时页面的底栏行为保留。

统计页底部留白使用 RecordDock 实测高度并预留间距，支持安全区域；录制计时使用完整 PCM 的采样时间，避免底栏计时和报告不一致。

## 统一参考内容（2026-10-19）

横竖屏均移除朗读/自由说话模式切换，只提供三篇短文的选择：雨后的街道、清晨的公园、一件小事，不提供无参考内容或话题提示选项。默认显示第一篇短文。仅读取和分析过程中锁定选择，录音和暂停可切换。所有短文使用同一录音与统计流程，按选择顺序保存参考短文的去重快照；报告统一使用「录音」来源标签。

## 统计分析页 B 版竖屏阅读卡（2026-10-19）

768px 及以下把字号按钮放在文章标题右侧同一行，移除阅读卡顶部的独立工具行。参考内容选择放在 RecordDock 左侧，麦克风居中，有旧报告时右侧显示「查看上次结果」；左侧在各阶段保留文章选择器，仅读取和分析期间禁用；取消和失败后的重新准备移到顶部更多菜单。取消独立设置栏、材料来源与预计时长、准备状态、页面计时和阅读卡底部说明。保留标题与正文，正文默认 20px、1.8 倍行高，横屏仍默认 22px，手动选择字号在旋转与返回时保留；底部复用不透出的 RecordDock，录音计时仍在底栏显示。读取/分析进度及错误仍按任务状态出现，取消持续可达。

横屏保留独立设置栏与计时。参考内容选择控件由两种布局共用，录音期间同样可切换，读取与分析期间锁定，旋转窗口不重置参考内容、字号或录音会话。

竖屏阅读状态下，main 与阅读卡使用剩余空间的固定高度，不随正文滚动；卡头标题与字号固定，article 内部滚动，支持键盘聚焦与触摸滚动。底栏实际高度计入可用空间，正文末尾不被 RecordDock 遮挡。结果报告仍保留页面滚动，横屏滚动方式不变。

底栏参考内容使用固定向上展开的菜单，避免原生选择框在底部向下弹出越界。菜单按屏幕高度限制高度并在内部滚动，仅列出三篇短文并保留当前选中标记；支持方向键、Home/End、Escape、点击外部关闭及选择后恢复按钮焦点。横屏保留原生选择框。


## 独立只读报告与来源返回（2026-10-19）

录音页 `/recording` 负责材料、字号、采集、导入、分析及失败重试。分析成功后发布独立 UUID 记录，录音页仍活动时自动打开 `/reports/:reportId`；后台成功仅更新可查看记录，不抢占其他路由。取消或失败停留录音页，上一份成功记录保留，只有新分析成功才替换。

详情只读，当前显示「返回录音」，来源上下文与报告数据分离；未来列表来源可显示「返回列表」。从应用入口打开详情后返回使用上一条历史，避免录音/详情历史循环；无来源默认替换至录音页，无效 ID 显示「报告不存在或已失效」。当前仅保留内存中的一份成功记录，刷新后失效，不实现持久化与历史列表。

返回暂停回放、保留进度和录音页材料/字号，不开始录音或分析。录音页有记录且非忙碌时显示「查看上次结果」；查看旧记录不丢失失败任务的 PCM，回来仍能重试。详情不包含录音、导入、重试、清除、保存或再录操作；未来仅含统计而无音频的记录隐藏回放控件。

横屏详情的来源返回仅在顶栏，竖屏仅在标题右侧且不渲染 RecordDock。录音页继续沿用横屏顶栏与竖屏 Dock、向上短文菜单、article 内部滚动和实测底栏间距。旋转不更换路由或记录，不启动任务或播放。


## 统一帮助主题（2026-10-19）

统计分析接入同一个 HelpDrawer/Modal 的七项主题导航，不再按页面隐藏导航或替换正文。从统计页更多菜单打开默认选中「统计分析」，其他页面通用入口默认快速上手，定向问号仍打开指定主题。关闭再打开由新入口决定默认主题；打开期间的旋转、路由或任务阶段变化不重置用户选中主题。主题切换正文回顶，旋转只更新当前主题的横竖屏操作位置说明。

横屏主题按钮四列、竖屏三列自然换行，关闭固定可达、正文沿用弹窗滚动。统计主题包含录音准备、导入与完整回放、中位数/P10/P90、60–500Hz 过滤与数据恢复；报告内统计说明继续保留。帮助开关与主题切换不暂停录音/回放或发起任务，后台分析自然成功/失败不抢占模态焦点。原入口失效时关闭帮助优先返回当前帮助/更多入口；首次使用提示自身关闭仍优先录音按钮。统计图不添加男女声参考范围。


## 竖屏报告标题操作（2026-10-19）

竖屏报告标题与「返回录音」（或来源对应文案）同行，按钮高度至少 44px，使用可见文字并随报告自然滚动，不吸顶或悬浮。结果页整块卸载 Dock，布局上下文高度即时为 0，底部仅常规 28px 间距与设备安全区；不留空白外壳或旧 Dock 高度。准备及任务阶段恢复 Dock 和按实测高度预留的正文空间，阅读区内部滚动不变。

正常、样本不足及无有效 F0 结果均采用相同结果布局。返回录音页和查看上次结果保留成功记录及回放位置，不启动录音或分析。横屏保持唯一的顶栏入口，不在报告内重复按钮。帮助按横竖屏说明正确位置。


## 2026-10-20 录音暂停与就地帮助

录音页录制按钮依次为开始录音、暂停录制、继续录制，只有暂停后点击独立的「完成录制」才进入分析。累计样本达 60 秒自动暂停、继续禁用，仍可完成或取消。暂停释放设备，草稿保留；继续重新连接设备，暂停时间不计入时长、不补静音，旧报告入口在草稿期间锁定，材料可以切换且不影响音频与计时。继续授权或采样率变化失败保留既有草稿，可完成分析或取消；切页保留暂停草稿，不能自动分析。

统计 Dock 三个等宽轨道，各列控件居中，中央按钮固定在窗口中线；长标题省略，完成文案可分行但保持完整可访问名称及至少 44px 点击高度。首次准备右列留空，已有报告时右列查看上次结果，暂停后右列完成。报告详情继续无 Dock。

横屏设置条不显示原创来源和预计时长，阅读卡底部改为「不知道怎么用？」链接外观按钮，打开原使用说明的统计分析主题并支持焦点返回。竖屏不增加底部帮助工具行，沿用更多菜单。

统计录音页首次提示显示「了解录制、暂停和统计结果」，共用全局关闭/完成标记，查看说明进入统计主题；准备/暂停可见，授权/录音/导入/分析和弹窗打开时暂隐藏，详情不显示。提示脱离文档流，悬浮在 Dock 上方；阅读区只为 Dock 预留空间，不计提示高度，提示显隐不能改变阅读卡高度。文章仍只在 article 内滚动。

## 共享基础 DSP

实时完整分析与统计 Worker 均调用 `BaseAnalysisPipeline`，统一重采样、分帧、真实尾部证据、门控与原始 F0。主页面在基础帧上计算共振峰、平滑和声区；统计页不调用这些可选阶段，只做 60–500Hz 过滤、跳点排除和分布计算。共享检测范围仍为 60–1000Hz，分析配置引用同一基础常量，统计版本为 recording-f0-v3；页面状态、调度与音频窗口继续分开。


## 2026-10-20 Dock 状态设计落实

左侧固定文章选择器，中央沿用 RecordDock 圆形按钮，右侧使用共享 Button 的 ghost 样式；两侧都是 44px 高、12px 字号、12px 圆角及浅色细边框，填满各自等宽轨道。准备时右侧可查看上次结果；录音/授权时完成录制保持可见且禁用，暂停且有音频时启用；读取/分析时两侧禁用。取消录音/导入/分析以及失败后的重新准备统一在竖屏更多菜单，横屏仍可直接操作。
