# 在线声音训练 · UI 与帮助交互规范

更新于 2026-10-15。本文记录当前实现；竖屏视觉细节见 `ui-design-portrait.md`，历史方案见 Git 历史及 `docs/superpowers/`。

## 页面与主要操作

- 「声音分析」显示基频、共振峰、训练目标和实时反馈；「音高参考」显示钢琴键盘与音高图。
- 宽度超过 768px 使用横版：顶栏提供录音、导入音频、回放、清空、配置、帮助、关于及页面切换。
- 宽度不超过 768px 使用竖版：顶部 Tab 切换页面，更多菜单提供导入、配置、帮助等操作，底部提供录音、清除与回放；声音分析页另有当前目标入口。
- 帮助、配置、关于及目标设置同时只打开一个；阅读帮助不停止录音或回放，不申请麦克风权限。

## 主动帮助入口

不显示随机小提示，不自动打开帮助模态框。横竖屏共用一次性的首次使用悬浮提示，记录同一个本地关闭/完成标记。

| 入口 | 打开的主题 |
|---|---|
| 顶栏「帮助」 / 竖屏「更多 → 帮助」 | 快速上手 |
| 首次使用悬浮提示「查看说明」 | 快速上手 |
| 基频、共振峰标题旁的问号按钮 | 读图与反馈 |
| 音高图标题旁问号 | 音高参考 |

- 图表说明通过点击打开，支持键盘操作，不依赖悬停。
- 两端空状态均仅保留说明，帮助通过一次性悬浮条、图表问号或菜单主动打开。
- 空状态保持事件穿透；悬浮条仅卡片接收点击，不拦截图表其他区域。
- 目标卡片不增加「ⓘ 规则」入口；原有必要的校验气泡继续使用。

### 共享首次使用悬浮提示

- 标题「第一次使用？」、副文案「了解录音、读图与目标设置」，按钮「查看说明」，右侧可关闭；只打开帮助文档，不提供交互式步骤引导。
- 脱离文档流：横屏右下角距右/底边 24px、宽 400px；竖屏在实际底部操作栏上方 10px，左右 12px、最大宽 400px。不改变图表高度，定位外层保持事件穿透。
- 声音分析与音高参考页共用一份状态。无数据空闲时显示；授权、录音、回放、已有数据或设置弹层打开时暂时隐藏。
- 关闭或首次产生任一有限且 >0 的 F0/F1/F2 分析值后持续隐藏，录音与导入同样适用。仅查看帮助不计为完成。
- 本地键 `voicebuilder-intro-hint-v1` 仅保存布尔标记；清空图谱不清除它。存储受限时当前会话仍有效，刷新可能再次出现。无历史标志的老用户首次上线也可能看到一次。
- 横竖屏空状态均不放置上手/音高说明按钮，标题问号与菜单/顶栏帮助持续可用。

## 帮助面板

使用共享 Modal，标题为「使用说明」，正文顶部有六个主题按钮：快速上手、读图与反馈、训练目标、录音与导入、遇到问题、音高参考。

- 快速上手分为开始录音、观察自己的声音、选择目标并回放三步。
- 根据当前横竖屏说明实际操作位置；切换布局保留当前主题。
- 章节切换后正文回到顶部；长内容在正文区域滚动，关闭按钮保持可用。
- 支持 Esc 关闭、Tab 焦点约束，关闭后焦点返回原入口；入口已退出或不可见时返回当前录音按钮，录音禁用则退到横屏帮助/竖屏更多。跨布局不重新聚焦帮助正文或重置主题。
- 帮助文档不增加提示计时器或轮播；首次提示的隐藏规则和独立标记见上节。

## 数据来源与说明准确性

- 主题、文案统一由 `src/content/helpContent.ts` 维护。
- 默认元音表直接读取 `VOWEL_PRESETS`，只显示元音与 F0/F1/F2，明确它是默认值而不是用户自定义目标。
- 图谱可调范围、固定基频参考区间、最小间隔读取 `src/config/analysisRanges.ts`。
- 录音保留窗口、导入时长限制读取 `src/config/audioLimits.ts`，当前均为 10 秒；持续录音不会自动停止。
- 固定基频参考色带与可编辑训练目标分开说明；命中目标不代表对声音质量的完整评价。
- 按钮名使用「导入音频」；WAV、MP3、M4A 是否能解码取决于编码与浏览器支持。
- 数字输入失焦或 Enter 后提交，竖屏滑杆即时更新。恢复默认值清除全部元音自定义并切回 a，需确认。
- 排错分别说明权限、设备、无有效曲线、共振峰波动、文件过长或解码失败，避免统一要求刷新。

## 验收

检查横竖屏的入口、章节切换、焦点返回、360px 窄屏及矮屏正文滚动。保持录音、回放、导入和目标设置流程；页面静置后不出现自动随机提示。
