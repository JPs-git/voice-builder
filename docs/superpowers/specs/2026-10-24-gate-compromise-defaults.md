# 默认门控折中方案

日期：2026-10-24。范围：仅调整master现有门控默认配置。

## 产品行为

- 默认进入阈值0.010、退出阈值0.010、保持0ms；实时麦克风、文件导入与录音分析继续使用同一DEFAULT_VAD_OPTIONS。
- 目标为声带振动的持续元音，包括手机约20cm正常及较弱真声；不要求保护无振动轻声、气声。
- 低于门槛立即关闭；不新增迟滞或尾部保持。既有频谱否决与reset继续生效，显式门控覆盖接口保留。
- 录音分析版本由master的recording-f0-v3升级为recording-f0-v4，以区分默认参数变化；历史保存结果不追溯改写。
- 不修改共振峰估计、候选身份、平滑或历史恢复算法，不引入实验VAD、采集工具、模型、依赖或额外UI。

## 取舍与验证边界

本配置是已确认的产品折中选择，不代表所有声学问题解决。短弱段可能断线，噪声显示可能更碎，超过门槛的错误估计仍可能产生尖峰。
此前阈值扫描基于包含额外算法修复的研究版本；其量化结果不能直接作为本纯门控PR在master上的效果保证。研究代码、采集数据和实验记录保留本地，不纳入本PR；本次没有新的独立实机验收。

## 工程验收

- 默认参数固定为0.010/0.010/0；0.009 RMS不能打开，0.011 RMS可打开，降至0.009立即关闭；证据否决与reset有效。
- 既有低幅周期信号、六元音资产、麦克风原始PCM保存、流式/文件一致性和多采样率测试通过。
- 显式请求旧敏感配置时，迟滞与保持接口仍可使用；默认空选项使用新门控。
- npm test、npm run build、npx tsc --noEmit通过。
