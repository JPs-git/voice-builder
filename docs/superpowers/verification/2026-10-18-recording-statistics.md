# 录音统计实现验收记录

日期：2026-10-18。分支：`feat/recording-statistics`；基线：`7b4f18f`（已批准规格和计划）。

## 实现

独立 `/recording` 页面提供最多 60 秒录制/导入、朗读材料及自由说话。采集时不显示图表、不运行 F0 分析。录后本地 Worker 分析完整 PCM，输出中位数、实际极值、变化幅度、半音跨度、P10–P90、有效时长、时间曲线和分布；支持完整回放、定位和局部回听。旧页面的 10 秒音频窗口保留。

## 验证证据

- `npm test`：80 个文件、568 项测试通过，退出 0。
- `npm run build`：通过，退出 0。现有主包大小警告仍存在。
- `npx tsc --noEmit`：通过，退出 0。
- 浏览器：1440×900、1920×1080、360×800；26px 阅读正文无横向溢出；自由说话提示收起/显示、切页保留报告已验证。
- 45 秒合成 PCM WAV：完整导入并生成报告；极值定位、显式局部回听正常。61 秒文件被拒绝，上一份结果保留。
- 最终浏览器复查：12 秒合成 WAV 生成报告；播放中选择极值会暂停并定位，未自动重新播放。
- 自动回归：按样本截断 60 秒；Worker 取消和旧消息隔离；授权晚返回释放音轨；失败保留 PCM；中断和无初始输入恢复；实际 ECharts 缩放在游标更新后保留。

合成输入只验证流程，不证明真人自然说话的识别效果。真实麦克风授权、朗读、即兴说话与低音量效果尚未实测；采集和取消状态由自动测试覆盖。

## 独立审查及修复

独立审查发现三项 Important 问题，均以失败测试复现后修复，并完成最终全量验证：

1. 回放游标更新重置图表缩放：初始化与游标增量更新分开，真实 ECharts 缩放回归通过。
2. 播放中点击极值自动继续播放：极值卡和曲线定位先暂停，进度条拖动保留连续播放行为。
3. 设备中断或没有初始音频时无法自动退出：增加按采集代次隔离的音轨结束通知；采集初始化成功后连续 5 秒没有输入则停止。有 PCM 时分析已录内容，无 PCM 时恢复准备状态并提示。

未遗留 Critical/Important 问题；没有延后处理的 Minor。

## 本轮决定与验证边界

1. 真人及低音量收音保留未实测标记，使用自动测试验证采集状态，合成输入验证完整流程；代价：真实设备仍可能暴露收音或门控问题。
2. 视觉验收由实现者在浏览器完成，独立审查未重复；代价：其他浏览器可能有未发现的布局差异。
3. 旧实时页面导入任务晚完成的原有行为维持现状，与新报告分开存储；代价：离页后旧图谱仍可能完成更新。
4. 未开展低端设备性能基准测试，已移除每次游标更新时重建整个图表的行为；代价：低端设备仍可能出现处理或回放延迟。

实现保留在工作分支，尚未推送、创建 PR 或合并。
