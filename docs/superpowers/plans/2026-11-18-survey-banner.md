## 推荐方案与边界

推荐在 AppShell 的工具栏与 Outlet 之间，仅匹配 `/` 时显示正常文档流横幅。独立 SurveyBanner 组件负责文案、问卷链接和关闭操作，沿用现有颜色变量和按钮样式。不引入依赖。

替代方案：悬浮横幅更醒目，但与 FirstUseHelpBanner 和移动端 RecordDock 争用空间；分析页内嵌卡片侵入两个方向的分析布局。推荐顶部横幅，实施时须验证固定视口下图表可用高度。

已确认文案（逐字使用）：“为了优化产品体验, 诚邀您参加2分钟左右的问卷调查!”。按钮建议：“参与调查”。问卷链接：`https://v.wjx.cn/vm/PLHDDnU.aspx#`；活动 ID 使用 `PLHDDnU`。建议在新标签页打开并带 rel="noopener noreferrer"，避免中断当前训练。不额外声明匿名性或奖励。

建议提供关闭按钮，仅在当前标签页会话内保持关闭（sessionStorage），以问卷 ID 区分活动；存储不可用时降级为组件内状态。不把跳转当作已完成问卷。不新增统计事件或问卷表单。
